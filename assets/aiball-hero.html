Async by design
Wakes fire at turn-end, never mid-thought. The backlog drains itself between turns.
Hybrid control
Drive Claude live in the terminal, or queue tickets and leave. Same session, same context.
Per-project memory
One loop per repo, alive between turns. Deep work at scale — flow preserved across projects.
Remote
Moderate, comment and queue from your phone over a private tailnet. Storage stays local.
Under the hood: tmux + Claude Code hooks (SessionStart / Stop) + a PTY proxy. No magic.
